# V5.7 — Release Hardening Android

## Objectif

Transformer la base V5.6 en build Android plus proche d'un artefact de production,
sans ajouter de moteur pédagogique lourd.

## Changements

- `versionCode` : 57
- `versionName` : 5.7.0
- minification R8 activée pour `release`
- `shrinkResources` activé
- configuration de signature release par variables/propriétés, sans clé privée dans le projet
- règles R8 dédiées à Capacitor et aux classes de l'application
- permission `POST_NOTIFICATIONS` préparée pour Android 13+
- permission `INTERNET` retirée : l'application web est offline-first et ne fait pas de requête réseau applicative
- intent-filter Android pour `application/epub+zip`
- package.json/package-lock alignés sur 5.7.0

## Limites vérifiées

Le plugin `@capacitor/local-notifications` n'est pas présent dans les dépendances V5.7.
La présence de `POST_NOTIFICATIONS` prépare le manifeste, mais ne suffit pas à elle seule
à activer les notifications natives. Le code V5.6 garde un comportement gracieux si le
plugin n'est pas disponible. L'intégration native complète des notifications sera faite
uniquement avec le plugin effectivement installé et synchronisé.

L'ouverture EPUB depuis un gestionnaire de fichiers est déclarée au niveau Android,
mais le transfert automatique du `content://` vers `handleFile(File)` n'est pas prétendu
comme terminé dans cette version.
