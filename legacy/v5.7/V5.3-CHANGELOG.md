# V5.3 — Moteur de sélection et génération pédagogique

## Objectif
Faire évoluer la lecture active d'un simple menu d'actions vers un moteur qui aide à décider **quoi apprendre, pourquoi et comment le rappeler**.

## Nouveautés
- Analyse pédagogique locale et offline d'un passage sélectionné.
- Classification heuristique : définition, cause/conséquence, comparaison, séquence/procédure, exemple/application, donnée précise, relation, concept, verbatim.
- Score de valeur d'apprentissage sur 100, combinant densité, longueur utile, spécificité pédagogique et nouveauté par rapport aux fiches du chapitre.
- Proposition automatique d'un exercice adapté au type de passage.
- Bouton « Créer l'exercice recommandé » dans la fenêtre de lecture active.
- Détection de doublons approximative pour éviter d'accumuler des fiches redondantes.
- Mode professeur basé sur le type pédagogique détecté, avec questions de compréhension, rappel, séquence et transfert.
- Évaluation du rappel améliorée par une normalisation/stemming léger du vocabulaire français, tout en restant entièrement locale.
- Palais de mémoire refactorisé : handlers dédiés, coach d'encodage et test spatial séparé du mode professeur.
- Rappel spatial : lieu → scène → action/interaction → vérification.
- Le système conserve la règle pédagogique « rappel avant révélation ».

## Principes
- Une activité d'apprentissage n'est pas automatiquement une preuve de maîtrise.
- Le moteur recommande un exercice, mais laisse toujours l'utilisateur choisir une autre action.
- Aucune API distante ou génération IA n'est nécessaire : V5.3 reste offline-first.

## Correction technique
- Suppression du mécanisme V5.2 qui remplaçait temporairement les `onclick` du mode professeur pour le palais.
- Le mode professeur et le palais disposent maintenant de fonctions d'évaluation et de navigation dédiées.

## Validation
- JavaScript extrait du HTML vérifié avec `node --check` : aucune erreur de syntaxe.
