# V5.6 — Consolidation pédagogique & UX

## Objectif
Consolider le parcours d'apprentissage sans ajouter de bibliothèque, modèle IA ou service distant.

## Changements
- Le tableau de bord ne traite plus les fiches non testées comme des échecs de compréhension.
- « Compréhension prouvée » = fiches ayant une tentative active réussie / fiches effectivement testées.
- « Fiches testées » distingue l'activité réelle de l'absence de données.
- Le taux de rappel du tableau de bord est calculé sur les fiches réellement révisées, pas sur toutes les fiches.
- Le mode professeur ne génère plus artificiellement une question de transfert pour chaque concept : le transfert est proposé lorsque le passage est réellement classé « exemple/application ».
- Clarification UX du tableau de bord : une absence de test n'est pas une compréhension ratée.

## Performance
- 0 nouvelle dépendance.
- 0 modèle embarqué.
- 0 requête réseau.
- Les calculs supplémentaires sont effectués uniquement à l'ouverture du tableau de bord ou du mode professeur.
